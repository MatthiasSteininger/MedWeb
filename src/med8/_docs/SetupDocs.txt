i used the msi installer: node -v / npm -v / npx -v -> should yield the most recent versions

Setup React Web App (note that CRA - Create React App is not maintained anymore and it is suggested to use vite)
    npm create vite@latest

    npm install
    npm run dev

Tailwind:
    npm install -D tailwindcss postcss autoprefixer
    npx tailwindcss init -p

Extensions:
    es7 react / redux / react - native
    tail wind css
